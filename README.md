# Сайт Валерии Фридлендер

Текущая версия проекта основана на проверенной копии сайта из исходного архива
Tilda. Вёрстка и визуальная композиция сохранены; метаданные, индексация и
технические SEO-настройки обновлены отдельно от будущего редизайна.

## Структура

- `public/index.html` — исходная главная страница;
- `public/page*.html` — остальные страницы экспорта;
- `public/css`, `public/js`, `public/images`, `public/files` — стили, скрипты,
  оптимизированные изображения и содержимое исходного экспорта;
- `app` и `.openai` — оболочка для проверки и публикации проекта.

## Оптимизация изображений

Скрипт `scripts/optimize_assets.py` по умолчанию удаляет только точные дубли,
не меняя пиксели и формат оригиналов. После новой выгрузки его можно запустить
повторно:

```powershell
python scripts/optimize_assets.py
```

Для отдельной тестовой копии доступен режим `--webp`: прозрачная графика в нём
кодируется без потери пикселей, а фотографии принимаются только после строгой
проверки качества.

Исходная неоптимизированная версия остаётся доступна в истории Git.

## SEO

Скрипт `scripts/update_seo.mjs` синхронизирует уникальные `title`, `description`,
Open Graph, X/Twitter, canonical, `lang`, структурированные данные и правила
`noindex` во всех экспортированных страницах. Он также сохраняет нейтральное
позиционирование психолога для всех клиентов, без ограничения аудитории по полу.

Черновые, дублирующиеся и устаревшие страницы исключены из `sitemap.xml` и
закрыты от индексации до содержательного обновления. Чистые адреса страниц
поддерживаются и на основном хостинге, и в опубликованной тестовой копии.

## Репозитории

- закрытый репозиторий хранит постоянный архив проекта;
- открытый репозиторий используется как временная копия для просмотра.

Следующий редизайн следует вести отдельной веткой или отдельной рабочей копией,
не изменяя эту базовую версию.

Базовая копия проверена на широком и мобильном экранах 16 августа 2026 года.

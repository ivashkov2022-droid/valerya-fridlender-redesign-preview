# Сайт Валерии Фридлендер

Текущая версия проекта — точная базовая копия сайта из исходного архива Tilda.
Она сохранена без редизайна, сокращения текстов и перестройки блоков, чтобы дальнейшие
изменения можно было делать от проверенного оригинала.

## Структура

- `public/index.html` — исходная главная страница;
- `public/page*.html` — остальные страницы экспорта;
- `public/css`, `public/js`, `public/images`, `public/files` — оригинальные стили,
  скрипты, изображения и содержимое;
- `app` и `.openai` — оболочка для проверки и публикации проекта.

## Репозитории

- закрытый репозиторий хранит постоянный архив проекта;
- открытый репозиторий используется как временная копия для просмотра.

Следующий редизайн следует вести отдельной веткой или отдельной рабочей копией,
не изменяя эту базовую версию.

Базовая копия проверена на широком и мобильном экранах 16 августа 2026 года.
